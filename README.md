## Project Description

This lab explores two fundamental types of supervised machine learning: **Regression** and **Classification**.

Using the Titanic dataset, the lab applies:

- **Linear Regression** to predict passenger `Fare` using features such as `Age` and `Pclass`.
- **Logistic Regression** to predict whether a passenger `Survived` using `Age`, `Pclass`, and `Sex`.

The workflow includes preparing the dataset, splitting the data into training and testing sets, training the models, making predictions, and evaluating model performance using appropriate metrics.

For the regression model, performance is evaluated using **Mean Squared Error (MSE)** and **Root Mean Squared Error (RMSE)**.

For the classification model, performance is evaluated using **Accuracy Score**.

This lab helped the team better understand the difference between predicting continuous numerical values and predicting categorical outcomes.
